# 阶段 Gate 与自动驾驶闭环

## Gate 顺序

1. **题目 gate**：研究对象、期刊方向、贡献类型、时间范围明确。
2. **检索 gate**：CNKI 检索式、同义词表、核心期刊清单、纳排标准完成。
3. **全文 gate**：用户授权下载后的全文状态台账可用。
4. **证据 gate**：来源清单、编码方案、claim ledger 与方法边界冻结。
5. **写作 gate**：正文不含工程化过程语言，图表有分母和口径。
6. **审稿 gate**：三轮审稿输出修订矩阵，作者或主 agent 决定采纳。
7. **发布 gate**：私库可含论文材料；公开库只能含通用 workflow 和脚本。

## 自动驾驶原则

agent 可以连续推进任务，但每个 gate 需要留下可复查文件。遇到缺全文、缺方法、缺数据、缺授权、疑似隐私泄露时，自动驾驶必须减速并说明阻断点。
