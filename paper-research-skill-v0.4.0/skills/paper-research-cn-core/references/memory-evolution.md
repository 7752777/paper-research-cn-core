# 本地记忆与自我进化

## 记忆可以保存

- 用户明确授权的写作偏好。
- 已确认有效的期刊规则摘要。
- 常见失败模式和修复方式。
- 已验证的中文核心表达范式。
- 任务复盘中的流程改进建议。

## 记忆禁止保存

- 账号、密码、cookie、token、验证码、机构授权信息。
- 私有论文全文、未公开数据、审稿意见原文、投稿系统截图。
- 未授权的作者身份、机构身份、通讯信息。
- 任何会绕过 CNKI、全文、真实证据、方法严谨和隐私保护 gate 的偏好。

## 晋升机制

1. 候选：记录来源、建议、适用场景和风险。
2. 复用：至少一次在类似任务中被成功使用。
3. 确认：用户或审计明确同意晋升。
4. 失效：期刊规则变化、用户偏好变化或审计失败时降级。
