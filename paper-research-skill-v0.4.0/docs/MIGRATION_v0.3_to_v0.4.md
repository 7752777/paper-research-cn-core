# 从 3.0 迁移到 4.0

3.0 的 `paper-research-cn-core` 和 `paper-review-cn-core` 仍作为私库历史版本保留，不在原目录原地堆叠。4.0 新增四个配套 skill，并把原本混在写作流程中的格式、图表、题录和投稿判断拆开。

迁移时先运行 `validate_package.py`，然后运行安装器的 `--dry-run`。确认替换列表只包含六个同名目录后使用 `--force`。项目脚本应把证据台账、数字审计、`doc.json`、图表/题注清单、参考文献审计、渲染记录和审稿矩阵作为独立输入保存。

历史项目若声称“核心样本”，必须重建材料类型和期刊层级字段；学位、会议、标准和综述不进入期刊核心分母。旧的“全部已解决”审稿记录必须由新的中文独立审稿和逐项修订矩阵替代。
