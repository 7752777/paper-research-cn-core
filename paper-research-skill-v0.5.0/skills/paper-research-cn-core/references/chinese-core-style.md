# 中文核心期刊语体

## 基本气质

像学者，不像项目经理。语言要紧、稳、可审计；少口号，多论证；少营销，多边界。

## 结构

- 题名：点明对象和方法/论证，不夸大新颖性。
- 摘要：研究目的、资料与方法、主要发现、结论贡献清晰，即使不显式加小标题也能读出结构。
- 引言：现实问题 -> 文献缺口 -> 研究问题 -> 贡献。
- 方法：交代来源、检索、样本、编码、分析和限制。
- 结果：先给发现，再给证据。
- 讨论：解释理论和实践意义，再给有边界的局限。

## 图表

- 默认中文标签、灰阶友好。
- 表题说明分析对象。
- 表注定义分母、缺失值、编码规则和缩写。
- 不写“数据来自 xxx.csv”，改为说明语料构建、资料来源类型和统计口径。

## 结论强度

- 描述性证据用“显示”“表明”“提示”“可见”。
- 探索性发现用“可能”“有助于”“提供线索”。
- 只有研究设计支持因果时才使用因果语言。
- 未直接测量时，不泛称全国现状、实际效果、用户心理或治理成效。
